# MU Asset Lab

Read `AGENTS.md` for project rules and `docs/architecture.md` for the registry. For the Budge Dragon, read `docs/dragon-v2-readiness.md`, `docs/monster03-v0002-experiments.md` and `contracts/monster03-unity.json` before proposing a build: Blender validation comes first by user choice, Unity/OpenMU is the eventual target, and the GLB is an unapproved reference. Use `py -3.9 tools/registry.py show <asset-id>` to load only the relevant asset and version. Record every experiment and validate the registry before finishing.

The reusable one-command prototype and its limits are in `docs/monster-engine.md`; Monster03's explicit profile is `profiles/monster03.json`.
